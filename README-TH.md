# JN LAO CARS Mobile

แอปเว็บติดตั้งได้ (PWA) แยกจากเว็บไซต์หลักโดยสมบูรณ์

- ไม่แก้ไขเว็บหลักหรือฐานข้อมูล
- เมื่อเปิดแอป จะไปยังคลังรถ HTTPS เดิมเพื่อใช้ระบบล็อกอินและข้อมูลชุดเดิม
- Android: เปิดลิงก์แอปใน Chrome แล้วเลือก **ติดตั้งแอป**
- iPhone: เปิดลิงก์แอปใน Safari แล้วเลือก **เพิ่มไปยังหน้าจอโฮม**

ก่อนใช้งานจริง ต้องเผยแพร่โฟลเดอร์นี้เป็นเว็บไซต์ HTTPS แยกต่างหาก
